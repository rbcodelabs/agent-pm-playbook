# Roadmap Workflow

Read the full relevant roadmap, linked Solution validation, the active Outcomes and key results, policy, and capacity in the host-injected active workspace through host-provided Compass MCP tools. Every roadmap item should trace up its Loop chain (Solution, key result, Outcome, Opportunity); name any item whose chain is broken.

Treat Later as the candidate pool, Next as validated and capacity-ranked work, and Now as an explicit delivery commitment. Validation alone does not move an item to Next or Now. When Next is full, compare the candidate with every existing item and show any required displacement.

Present proposed moves with evidence, tradeoffs, and capacity effects, and list key results with no active work rolling up to them. Obtain the user's product judgment before prioritization, displacement, or commitment. Re-read current state immediately before an authorized mutation, then verify the result. Preserve rejected or deferred candidates in Later with rationale.

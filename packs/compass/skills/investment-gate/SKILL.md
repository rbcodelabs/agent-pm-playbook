# Investment Gate

Read the candidate and linked outcome, evidence, assumptions, experiments, and roadmap state from the host-injected active workspace using host-provided Compass MCP tools.

Assess readiness across outcome alignment, evidence strength, solution validation, risk reduction, delivery clarity, and learning or success measures. Return `ADVANCE`, `HOLD`, or `STOP` as a recommendation with cited Compass record IDs, unresolved gaps, and the evidence that would change the result.

An assessment never grants commitment authority. Do not advance status or roadmap horizon unless the user separately authorizes that mutation and the host exposes the required tool. A tracking decision is context, not execution permission.

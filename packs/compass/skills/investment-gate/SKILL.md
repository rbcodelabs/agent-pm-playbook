# Investment Gate

Read the candidate Solution and its chain (key result, Outcome, Opportunity), plus evidence, assumptions, Tests, and roadmap state, from the host-injected active workspace using host-provided Compass MCP tools.

Assess readiness across Outcome and key result alignment, Opportunity evidence strength, Solution validation, risk reduction, delivery clarity, and learning or success measures. Return `ADVANCE`, `HOLD`, or `STOP` as a recommendation with cited Compass record IDs, unresolved gaps, and the evidence that would change the result. A broken chain (no key result, no Outcome, no Opportunity) is a gap to name.

An assessment never grants commitment authority. Do not advance status or roadmap horizon unless the user separately authorizes that mutation and the host exposes the required tool. A tracking decision is context, not execution permission.

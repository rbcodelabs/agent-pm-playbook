# OKR Workflow

Use the host-injected active workspace and host-provided Compass MCP tools to read the current OKR cycle, objectives, key results, and linked product outcomes.

Objectives describe meaningful direction; key results are measurable outcomes with a baseline, target, owner, and time boundary. Reject feature delivery as a key result. For check-ins, record the observed value, date, confidence, evidence, blockers, and next learning action without fabricating missing measurements.

Show drift between active discovery or roadmap work and the stated key results. Creating an OKR, changing a target, or closing a cycle requires the user's product judgment. Verify every authorized mutation against the returned object.

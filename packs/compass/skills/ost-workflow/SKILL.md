# OST Workflow

Read the current tree in the host-injected active workspace using host-provided Compass MCP tools before proposing changes.

Maintain one measurable desired outcome per tree. Frame opportunities as customer needs, pains, or desires; never as features. Link multiple solution directions to a selected opportunity, identify assumptions within each solution, and connect each experiment to the assumption it tests.

For a health check, assess outcome clarity, opportunity framing, evidence, focus, experiment velocity, orphaned records, and stale branches. Cite the Compass records supporting each finding. Never silently prioritize a branch: present the evidence and obtain the user's product judgment before recording focus or priority changes.

Archive invalidated or abandoned branches with reasons. Do not erase the learning trail.

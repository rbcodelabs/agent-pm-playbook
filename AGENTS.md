# Agentic PM Playbook repository

This Git repository is canonical for playbook documents, skills, agents and tests.
Work in an isolated Git worktree on a feature branch. Use normal Git commits, pushes
and pull requests; preserve unrelated work. Merge and release require their own authority.

`Playbooks/Agentic PM Playbook/` in the vault is an optional reference mirror.
Vault Bridges is not required for editing, publishing or delivery. Older instructions
requiring bridge pushes or prohibiting Git are superseded. Use a bridge only for an
explicit mirror-sync request; never make its availability a prerequisite to repository work.
